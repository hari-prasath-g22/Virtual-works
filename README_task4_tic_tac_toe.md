# Task 4 — Tic-Tac-Toe

A two-player console game on a 3×3 board. Players X and O alternate by choosing numbered cells. The game validates moves and detects wins and draws.

## Compile and run

```bash
g++ -std=c++17 -Wall -Wextra -pedantic task4_tic_tac_toe.cpp -o tic_tac_toe
./tic_tac_toe
```

On Windows with MinGW, build as `tic_tac_toe.exe` and run that executable.
