# Task 1 — Basic Calculator

A menu-driven C++17 console calculator supporting addition, subtraction, multiplication, and division. It validates menu/numeric input and prevents division by zero.

## Compile and run

```bash
g++ -std=c++17 -Wall -Wextra -pedantic task1_calculator.cpp -o calculator
./calculator
```

On Windows with MinGW, replace the output with `calculator.exe` and run `./calculator.exe` (or `calculator.exe` in Command Prompt).
