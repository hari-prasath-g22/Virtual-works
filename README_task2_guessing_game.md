# Task 2 — Number Guessing Game

The program randomly selects an integer from 1 to 100. Keep guessing to receive “Too High” or “Too Low” hints; it counts guesses and supports replay.

## Compile and run

```bash
g++ -std=c++17 -Wall -Wextra -pedantic task2_guessing_game.cpp -o guessing_game
./guessing_game
```

On Windows with MinGW, build as `guessing_game.exe` and run that executable.
